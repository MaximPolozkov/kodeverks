# IT-студия: сайт, админ-панель и бот для поиска клиентов

Публичный сайт студии (услуги + форма заказа) и закрытая панель `/admin` с заказами, профилем,
управлением пользователями и ботом, который ищет клиентов в соцсетях и ведёт их к форме заказа.

**Стек:** React 18 + TypeScript + Vite + Tailwind · FastAPI · SQLAlchemy 2 (async) · PostgreSQL 16 ·
Alembic · ARQ + Redis · Docker Compose.

## Быстрый запуск

```bash
cp .env.example .env        # задайте SECRET_KEY, пароли и FIRST_ADMIN_*
docker compose up -d --build
```

- Сайт: http://localhost:8080
- Панель: http://localhost:8080/admin (адрес `/Admin` тоже работает)
- Документация API (Swagger): http://localhost:8000/docs при локальном запуске бэкенда (см. ниже)

При старте контейнер `backend` сам применяет миграции (`alembic upgrade head`) и создаёт
администратора из `FIRST_ADMIN_EMAIL` / `FIRST_ADMIN_PASSWORD`, если его ещё нет.

## Локальная разработка без Docker

```bash
# Бэкенд (нужны PostgreSQL и Redis)
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
export DATABASE_URL=postgresql+asyncpg://itstudio:itstudio@localhost:5432/itstudio
export REDIS_URL=redis://localhost:6379/0
alembic upgrade head
FIRST_ADMIN_EMAIL=admin@example.com FIRST_ADMIN_PASSWORD=password123 python -m app.scripts.create_admin
uvicorn app.main:app --reload            # http://localhost:8000/docs
arq app.bot.worker.WorkerSettings         # воркер бота, в отдельном терминале

# Фронтенд
cd frontend
npm install
npm run dev                               # http://localhost:5173, /api проксируется на :8000
```

## Адаптивность и поддержка браузеров

**Экраны.** Вёрстка рассчитана на ширину от 320 px (iPhone SE) до 2560 px и больше:

| Ширина | Что меняется |
|---|---|
| 320–399 px | кнопки на всю ширину, у логотипа остаётся только значок (до 360 px), цены в калькуляторе в столбик |
| 400–767 px | мобильное меню, услуги в одну колонку, в админке заказы и пользователи — карточки вместо таблиц |
| 768–1023 px | меню сайта в шапке, таблицы в админке, меню админки по кнопке |
| 1024 px и шире | боковое меню админки, услуги таблицей, две колонки в первом экране и в блоке заявки |

Дополнительно: учёт вырезов экрана iPhone (safe-area), высота экрана без «прыжков» адресной строки
(`dvh` с запасным `vh`), поля ввода 16 px (iOS не зумит страницу при фокусе), кнопки не меньше 44 px,
hover-эффекты только на устройствах с мышью, перенос длинных email и ссылок.

**Браузеры.** Поддерживаются последние версии и версии за ~4 года:

| Браузер | Минимальная версия |
|---|---|
| Chrome, Яндекс Браузер, Opera, Samsung Internet (Chromium) | Chrome 87 / Opera 73 / Samsung 14 |
| Microsoft Edge | 88 |
| Firefox | 78 |
| Safari (macOS) | 14.1 |
| Safari и все браузеры на iOS/iPadOS | iOS 14.5 |

Как это обеспечено:
- `browserslist` в `frontend/package.json` — по нему Autoprefixer добавляет префиксы CSS;
- `@vitejs/plugin-legacy` понижает синтаксис JS и подключает полифилы только недостающих функций;
- CSS понижается до тех же версий (`build.cssTarget`);
- запасные варианты для `:focus-visible`, `dvh`, `backdrop-filter`, `matchMedia.addEventListener`,
  `scrollIntoView` с настройками, скачивания файлов в Firefox и Safari.

Internet Explorer 11 не поддерживается — Microsoft прекратила его поддержку в 2022 году.
Нижняя граница Safari 14.1 выбрана потому, что в нём появился `gap` для flex-раскладки, без которого
вёрстка рассыпается, а заполифиллить его нельзя.

## Уведомления о заказах во ВКонтакте

Когда клиент оформляет заявку на сайте, бот сообщества сразу присылает менеджерам сообщение
в личные сообщения VK (vk.ru/im). В сообщении есть номер заказа, имя, услуга, бюджет, источник,
описание задачи и выбранный клиентом способ связи. Под текстом две кнопки:
«Открыть заказ» ведёт в `/admin/orders/<id>`, «Написать в …» открывает диалог с клиентом
(t.me, vk.com, wa.me). Почту и телефон менеджер видит в тексте: кнопки VK открывают только https-ссылки.

Настройка:
1. В сообществе VK включите «Сообщения» и создайте ключ доступа с правом «Сообщения» → `VK_GROUP_TOKEN`.
2. Каждый менеджер один раз пишет сообществу любое сообщение (иначе VK запрещает боту писать ему первым).
3. В `VK_NOTIFY_PEER_IDS` перечислите их ID через запятую, например `12345678,87654321`.
   Можно добавить бота в общую беседу и указать её peer_id (`2000000000 + номер беседы`).

Быстрая настройка сообщества (club242635535): заполните `VK_GROUP_TOKEN`, `VK_GROUP_ID`,
`VK_NOTIFY_PEER_IDS`, `SITE_URL` и выполните
`docker compose exec backend python -m app.scripts.vk_setup --test` — скрипт включит сообщения и бота,
подключит Callback API, проверит получателей и пришлёт тестовое сообщение.

Уведомление уходит в фоне и не задерживает ответ клиенту. Если VK недоступен, заявка всё равно
сохраняется, а в карточке заказа будет «Уведомление во ВКонтакте: не отправлялось».

## Способ связи с клиентом

В форме заказа клиент выбирает, где ему удобно получить ответ: e-mail, Telegram, ВКонтакте, WhatsApp
или звонок, и указывает контакт. Сервер проверяет и приводит его к единому виду (`@ник`, `id123`,
`+79123456789`) и строит ссылку для перехода. Способ связи виден в списке заказов, в карточке
заказа (кликабельная ссылка), в выгрузке CSV и в уведомлении VK.

## Как устроен бот

1. **Поиск.** Воркер раз в N минут (настраивается во вкладке «Бот → Настройки») ищет публичные
   запросы по ключевым фразам:
   - **ВКонтакте** — `newsfeed.search` (нужен `VK_USER_TOKEN`);
   - **Telegram** — сообщения из групп, куда администраторы добавили вашего бота (приходят на вебхук);
   - **Сайты и биржи** — поиск через SerpAPI по списку доменов.
2. **Оценка.** Каждый пост получает оценку релевантности 0–100; посты со стоп-словами
   (вакансии, резюме) отбрасываются, дубликаты не сохраняются.
3. **Контакт.** Если включено «Писать найденным лидам первым», бот пишет только там, где это
   разрешено площадкой (во VK — пользователям, разрешившим сообщения от сообщества), с лимитами
   в час и в сутки. В первом сообщении бот представляется как автоматический помощник и предлагает
   написать «стоп».
4. **Диалог.** Ответы генерирует языковая модель (Anthropic или OpenAI-совместимый API) по инструкции
   из настроек; без ключа работает простой сценарий. Когда клиент готов к заказу, бот отправляет
   ссылку `SITE_URL/?ref=bot&lead_id=<токен>#order`. Заявка с этой ссылкой привязывается к лиду,
   лид получает статус «Оформил заказ».
5. **Отказ.** На «стоп», «не интересно» и т. п. бот замолкает и вносит автора в стоп-лист.
6. **Менеджер** может в любой момент открыть переписку, ответить сам — бот после этого не отвечает.

`lead_id` в ссылке — случайный токен, а не порядковый номер, чтобы по ссылке нельзя было
перебрать чужие лиды.

### Подключение вебхуков

- **Telegram:** `https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://ваш-домен/api/webhooks/telegram&secret_token=<TELEGRAM_WEBHOOK_SECRET>`
- **VK:** в настройках сообщества → Работа с API → Callback API укажите
  `https://ваш-домен/api/webhooks/vk`, строку подтверждения (`VK_CONFIRMATION_CODE`),
  секретный ключ (`VK_CALLBACK_SECRET`) и включите событие «Входящее сообщение».

### Ограничения, о которых стоит знать

- Telegram-бот не может написать пользователю первым и не видит чаты, куда его не добавили —
  это правило платформы. Лиды из Telegram-групп обрабатывает менеджер вручную.
- Массовые сообщения незнакомым людям нарушают правила соцсетей и могут нарушать закон о рекламе
  и 152-ФЗ. Держите лимиты низкими и не отключайте фразу про «стоп».
- Срок хранения лидов задаётся в настройках бота; старые неконвертированные лиды удаляются
  каждую ночь.

## Перед запуском в продакшене

- Замените название «Кодверк», контакты в футере и текст политики конфиденциальности.
- Поставьте длинный `SECRET_KEY`, `COOKIE_SECURE=true` и HTTPS перед nginx.
- Укажите реальный `SITE_URL` — он попадает в ссылки, которые отправляет бот.
